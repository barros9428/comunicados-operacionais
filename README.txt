ESCRITA CLARA - PARAFRASEADOR SEM IA

Arquivos: index.html, style.css, app.js
Hospedagem: GitHub Pages (estatico)
Nao necessita Cloudflare, API, chave ou backend.

INSTALACAO:
1. Extraia este ZIP.
2. Copie os 3 arquivos para a pasta local do repositorio comunicados-operacionais.
3. No CMD dentro dessa pasta:
   git add -A
   git commit -m "Recriar aplicativo sem IA"
   git pull --rebase origin main
   git push origin main
4. Abra https://barros9428.github.io/comunicados-operacionais/ e use Ctrl+F5.

IMPORTANTE: A reescrita usa regras e nao compreende livremente todas as frases.
O app informa quando as versoes podem permanecer semelhantes.
